# Orbit

Revenue, in orbit. A tiny sales dashboard built with Shiny and bslib, to try DirectoR on.

## Features

- **Overview.** Revenue, customers and growth at a glance, with a regional breakdown.
- **Explore.** Pick a region and a time window; the chart and trend line follow instantly.
- **Forecast.** Set a growth scenario and see the projected revenue months ahead.
- **Data.** Every monthly figure in one clean table.
